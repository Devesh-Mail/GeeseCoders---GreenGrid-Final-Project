GreenGrid runs inside other people's pages

GreenGrid does not need anyone to switch platforms to be useful. Any event page — AllCollegeEvent, a club's own site, a Google Site — can render a live GreenScore with a single script tag. The panel on the right is a mock third-party page using a completely different typeface, colour scheme and layout; the badge inside it is real, fetched live from this backend.

Rendered into a shadow root, so the host site's CSS cannot leak in and GreenGrid's styles cannot leak out. An embed that breaks somebody's layout gets deleted, so isolation is the feature.

Why this matters strategically

The usual hackathon pitch asks a platform to adopt a new app. This inverts it: the integration point already exists and already works, so the conversation moves from "please build this" to "this is already running, do you want it on your listings?" That is also the honest version of the business model — GreenGrid is infrastructure that makes AllCollegeEvent's existing pages richer, not a competing destination students must be persuaded to visit.
